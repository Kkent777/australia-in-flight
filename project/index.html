澳大利亚
国内航空网络

澳大利亚最繁忙的航线集中在哪里？如果把机场客流放回当地人口规模中，哪些城市会更突出？

我用 2014 年 7 月至 2026 年 2 月的月度航线记录追踪客流中断与恢复，再结合机场和城市人口数据比较区域差异。

个人工作

从源数据整理、指标设计，到交互开发和公开部署，由我独立完成。

数据清洗与整合
我将澳大利亚基础设施与交通研究经济局（BITRE）的航线与机场记录整理成可分析的明细表，再将机场年度旅客人次与澳大利亚统计局（ABS）的城市人口匹配。最终输出 4 份 CSV，并为各表记录来源、统计时段和字段口径。
指标与对照设计
我分别比较客流量、可用座位数和客座率，观察繁忙航线如何使用运力。对于区域机场，我将年度旅客人次除以对应城市人口，使不同规模城市的航空活动强度可以比较。
交互开发与部署
我用 Vega-Lite 编写地图、排名图、趋势图和热力图，用 JavaScript 加载图表，并在 Vega-Lite 中配置悬停读数。页面采用 HTML 和 CSS 响应式布局，通过章节导航连接五个专题，最终部署到 GitHub Pages。

小城市的客流强度

在截至 2025 年 11 月的一年里，凯恩斯机场的旅客人次相当于当地人口的 28.7 倍，悉尼为 8.1 倍。按人口换算后，城市对航空网络的使用强度呈现出与客流总量不同的格局。

旅客人次包括游客和往返旅客。该比值衡量机场客流相对于城市人口的规模，不能解释为当地居民的平均乘机次数。
